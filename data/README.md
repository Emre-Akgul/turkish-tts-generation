# Turkish TTS Arena Prompt Bank v1

`turkish_arena_v1.jsonl` contains 240 original Turkish utterances for blind,
pairwise TTS evaluation. The texts have automated structural validation but
have not yet been reviewed by native human annotators.

The `expected_reading` field is diagnostic metadata. It is never substituted
for `text` during synthesis.
